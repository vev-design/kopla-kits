# Event

A high-energy poster system for conferences, launches, and meetups: crisp
light ground, near-black ink, and a vivid rose accent used aggressively —
the event dates set as an oversized accent lockup and a solid scrolling
marquee strip as the signature motif. Display type is Archivo Black,
always uppercase with tight tracking and compressed leading, over an
Archivo body; the result reads like a gig poster that sells the ticket.

## Composition

Leads with a full-bleed poster **EventHero** — the event name and dates as
huge uppercase display type (dates in solid accent), the venue line, the
ticket CTA, and a scrolling accent marquee strip along the base repeating
the essentials — so the what/when/where lands with maximum energy. The
**Speakers** grid is the social proof, **Schedule** lays out the agenda
session by session, and **Tickets** converts with a highlighted recommended
tier. **Sponsors** adds credibility low on the page, and the **Footer**
repeats the essentials (date, location, code of conduct, contact). Every
section heading carries the same uppercase Archivo Black voice, and the rose
accent recurs throughout to tie the energy together; sections reveal on
scroll.
