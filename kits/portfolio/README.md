# Portfolio

A refined, image-forward portfolio system for designers, studios, and makers:
warm paper ground, near-black ink, a single terracotta accent, generous
whitespace, and big confident type. Display headings are set in Newsreader —
a variable serif with true italics — over Inter body and UI text; italic
serif accent phrases in terracotta (the intro's practice line, About's
heading, ProjectFeature's category lead-in) are the system's signature.
Built to let the work carry the page — project imagery leads, chrome stays
quiet.

## Composition

Opens with a type-only **Intro** — the name small at the top, an oversized
serif statement filling the viewport, an italic terracotta accent phrase,
and a quiet meta row (location, availability, roles) — so the typography
itself is the opening visual. The **WorkGrid** is the spine — a scannable
wall of covers — followed by one or more **ProjectFeature** beats that slow
down and go deep on a single piece (alternating image side for rhythm, an
italic serif category lead-in above each title). **About** is the human
counterpoint to the work, its heading set as an italic serif accent word,
and **Contact** closes with a single clear way to reach out before the
quiet **Footer**. Reveal/stagger motion brings each section in on scroll
without stealing focus from the imagery.
