# Editorial

Editorial is a longform, type-led design system in the tradition of print
newspapers and Sunday features. The default scheme is paper: near-white
background, near-black ink, and a single deep crimson accent that appears
only where it earns attention — a kicker, a drop initial, the mark on a
pull quote. The identity comes from print-newspaper detailing rather than
color: a centered serif nameplate with a double hairline rule beneath it,
ruled kicker/dateline strips, an oversized serif drop cap opening the lead
paragraph, hairline vertical rules between side-by-side columns, and
captions set as cutlines over a hairline. Headlines are set in a serif
display stack with tight tracking and a large scale; body copy runs looser
for comfortable reading. Margins are generous, columns are narrow enough to
read in a single sweep, and hairline rules do the structural work that
color and chrome do elsewhere. Reach for this system when the content is
the story — an essay, a feature, a manifesto, a long announcement — and you
want it to feel considered and printed rather than shipped.

## Composition

The chain reads the way a broadsheet feature unfolds top to bottom.
**Masthead** opens like a front page: a dateline strip between hairline
rules, the publication nameplate centered in the serif face over a double
hairline rule, then the headline, standfirst, and a centered byline — the
cover that establishes voice before a word of body copy. **ArticleHero**
follows as the editorial threshold: a ruled kicker/dateline block (crimson
kicker left, byline and date right), then the lead paragraph opened by an
oversized serif drop cap, and an optional full-bleed lead image with its
cutline. From there the body alternates rhythm: **ImageText** rows pair a
media block with a block of prose across a hairline column rule and flip
left/right via a variant so consecutive rows never feel mechanical — the
media column usually holds a photograph, or a small bar/line chart when the
beat turns on numbers — while **PullQuote** punctuates the read with an
oversized centered line that lets the eye rest and the argument land.
**GalleryGrid** opens the page back up into a multi-image spread, its tiles
separated by the same hairline column rules — the visual exhale before the
close. The piece then turns outward: **Newsletter** offers the reader a way
to keep reading, set as two ruled columns with the invitation on one side
of the hairline and the email capture on the other, and **Footer** closes
with ruled link columns and a centered colophon — the back page. Dense
type-led beats and sparse image-led beats trade off down the page, which is
what gives a longform read its pacing; scroll-triggered reveals carry each
beat in as it enters so the story unspools rather than arriving all at
once.
